Redefinir dados da demonstração

Volta a demonstração ao estado inicial: todas as notas dos exemplos passam a aparecer de novo como pendentes, prontas para serem conferidas e exportadas outra vez.

Ação destrutiva — leia antes de confirmar

Esta operação apaga tudo o que está no banco:

  • Notas importadas ({{ n_notas }} no banco). A lista fica vazia — e não reimporta sozinha. Para carregar de novo, use Importar manualmente depois.
  • Registro de exportação ({{ n_export }} nota(s) marcada(s) como já exportada). É a memória que impede pagar a mesma nota duas vezes.
  • Marcações de material aplicado feitas nas NFS-e (com autoria e data).
  • Artefatos de exportação ({{ n_artefatos }} arquivo(s) CSV em exportacoes/). Os lotes são arquivados no backup antes de a pasta ser esvaziada.

O que não é tocado: os arquivos XML de origem (em disco). Antes de apagar, cada banco e cada lote de exportação é copiado para uma pasta de backup datada, de modo que nada some de forma irreversível.
